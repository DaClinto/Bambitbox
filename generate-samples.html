🎵 DAW Studio - Demo Sample Generator

No audio samples? No problem!

Click the buttons below to generate demo drum samples that you can use in the DAW.

Each button will download a .wav file that you can load into the channels.

How to use:

  1. Click a button to download a sample
  2. Go back to the DAW at http://localhost:5173
  3. Click "+ Load Sample" next to a channel
  4. Select the downloaded .wav file
  5. Repeat for other channels
  6. Click grid cells to create a pattern
  7. Press Play and enjoy! 🎉
